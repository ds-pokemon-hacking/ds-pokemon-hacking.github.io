# Sprite Locations
> Author(s): [MrHam88](https://github.com/DevHam88) (*reformat for Wiki*)

---

Sprites and other graphics in Generation IV Pokémon games are spread across multiple NARC archives. A single visual element may use several files containing its image, palette, cell layout and animation, making it difficult to identify all the resources needed to edit it.

The reference tables in these pages, organised by game version, provide the archive locations and file mappings for known sprites, models and interface graphics, together with notes on shared resources and their use in game.
